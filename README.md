# Jennefer Homebrew tap

Homebrew packages for [Jennefer](https://jennefer.dev) on Apple Silicon Macs (macOS 12 or later).

```bash
brew install --cask jennefer-dev/tap/jennefer-hub
```

Jennefer Hub is the home of the Jennefer apps: chat with a local or cloud model and install the IDE, Studio, Workshop and more from one sidebar. The Hub updates itself after the first install.

The cask is generated from the published release by `scripts/distribution.mjs` in the Jennefer apps repository. Problems: [jennefer.dev/docs](https://jennefer.dev/docs).
